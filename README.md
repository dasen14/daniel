# Agente: estratega de clipping GTA 6

Agente de Claude Code (`.claude/agents/gta6-clipping-strategist.md`) con base de conocimiento en `knowledge/gta6-clipping/`, diseñado para funcionar con modelos inferiores: reglas fijas, fórmulas explícitas, umbrales de decisión y un fichero `estado.md` que guarda el progreso entre sesiones.

Uso: en Claude Code, invoca el subagente `gta6-clipping-strategist` o pide "actúa como mi estratega de clipping". Comandos: `estado`, `clip: ...`, `flojea: ...`, `tabla`, `evaluar`.
